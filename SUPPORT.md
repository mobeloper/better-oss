# Getting help

- **A question about using better-oss:** open a thread in
  [Discussions](https://github.com/mobeloper/better-oss/discussions) if it is
  enabled, otherwise a regular issue with the `question` label.
- **A bug or a wrong grade:** open an issue with the matching form. Include what
  you ran and paste the output.
- **A security problem:** do not open an issue. Use the private form in
  [SECURITY.md](SECURITY.md).
- **A conduct concern:** see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Common problems and their fixes are in
[docs/troubleshooting.md](docs/troubleshooting.md).

Before you ask, `python3 core/init.py --check` (or `/better-oss:init --check`
inside Claude Code) prints whether `git`, `gh`, `claude` and your `gh` login are
all in place; most setup problems show up there.

This is a single-maintainer project: answers are best effort.
